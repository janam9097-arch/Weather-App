# Weather App

A responsive weather application built with HTML, CSS, and JavaScript that retrieves current weather information from the OpenWeather API.

## Features

- Search weather by city
- Current temperature
- Humidity
- Weather conditions
- Responsive interface

## Tech Stack

HTML • CSS • JavaScript • OpenWeather API

## Configuration

If the application requires an OpenWeather API key, keep the key outside source control and load it through the project's configuration mechanism. Never commit API keys or other secrets.

## Run locally

Open `index.html` in a browser, or serve the project with a local web server if required by the application.
